# Пиксельный задачник — памятка для ИИ-ассистента

Проект делается вместе с нейросетями, и это не скрывается. Этот файл — точка входа для нового чата.
Подробности лежат в `docs/HANDOFF.md` (история решений, интеграции, данные) и `docs/MODS.md` (моды).

## Что это
Пиксельный таск-трекер в духе Loop Hero: узкая полоска у правого края экрана.
Одна веб-страница работает в трёх оболочках:
- **ПК** — Tauri 2, Windows, `src-tauri/`;
- **Android** — Capacitor, `mobile/`, APK собирает GitHub Actions;
- **сайт/PWA** — GitHub Pages публикует `web/`.

## Устройство (куда смотреть)
| Часть | Где |
|---|---|
| Всё приложение: разметка, CSS, состояние `S`, рендер, звук `SFX`, частицы `FX`, глаз-скины, синк, Google Календарь, настройки | `web/index.html` (один большой файл, разделы помечены комментариями `/* ===== … */`) |
| Карта по ✕ / «назад» | `web/bye.js` + `web/captions.json` |
| Хост модов: док снизу справа `#moddock`, песочница iframe, API `zadachnik.*`, «что играет» | `web/mods-host.js` |
| Встроенные моды (первый — «Пластинка») | `web/mods/<id>/` + `web/mods/index.json` |
| Rust-оболочка: окно-полоска, трей, курсор для глаза, iCal, Google OAuth, медиа-сессии Windows, папка модов | `src-tauri/src/main.rs` |
| MCP-сервер (Клод добавляет/закрывает задачи через файлы в `%APPDATA%\com.pixel.zadachnik`) | `mcp/server.js` |
| Сборка APK / сайта | `.github/workflows/android.yml`, `pages.yml` |
| Иконки | `make-icon.js` |

Ключевые имена в `index.html`: `S` (состояние, `localStorage["pixel-tracker-v1"]`), `LOCAL` (настройки только этого устройства, `pixel-local`), `save()`, `render()`, `SYNC` и `FB` (синк Firebase/Gist, `mergeDoc`), `GCAL`, `setSpec()`/`renderSettings()` (полки настроек), `replayDone()` (повтор отметок с другого устройства), `EYE_SKINS`/`eyeSvg()`, `window.dock` (мост к Tauri: **никогда не давать элементу `id="dock"`**, браузер затрёт этот мост).

## Как работать
- **Проверка без сборки:** любой локальный сервер на `web/`, открыть `index.html?mobile` (телефон) или `?fakemedia` (выдуманный плеер для модов). Новый дизайн сначала показывать **макетом** (файлы `web/_*.html` / `web/_*.js`, они в .gitignore), владелец выбирает, потом переносим.
- **Сборка exe:** `zadachnik.exe --quit`, затем `npm run build` → `src-tauri/target/release/zadachnik.exe`. Фронтенд вшит в exe, поэтому любое изменение `web/` требует пересборки.
- Патчи к большому `index.html` удобно делать скриптом на Node с точными заменами и затем проверять синтаксис (`new Function(js)`).
- В Tauri перетаскивание окна задаёт CSS `-webkit-app-region:drag` у `.top`. Всё интерактивное внутри шапки нужно помечать `no-drag`.

## Правила владельца
- Общение по-русски, коротко. Перед коммитом показать вживую, **коммит, push и релиз — только после его «да»**.
- Репозиторий публичный: никаких реальных задач, ключей, токенов, личных данных. Демо-данные только выдуманные. Чужие логотипы и ассеты не встраивать, рисовать свои пиксельные отсылки.
- Секреты (ключ синка, Google client secret, ключ подписи APK `%USERPROFILE%\.zadachnik-android.p12`) живут только локально или в секретах GitHub. Не печатать их и не снимать скриншоты настроек синка.
- Стиль: тёмный, золотые зубчатые рамки, пиксель-арт, CRT; звуки синтезируются в коде (ми минор).
