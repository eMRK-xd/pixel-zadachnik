Пиксельный задачник

Политика конфиденциальности · Privacy policy · обновлено 18.11.2026

Пиксельный задачник — личный трекер задач с открытым кодом (github.com/eMRK-xd/pixel-zadachnik). У приложения нет своего сервера: разработчик не получает и не хранит ничьи данные.

Где хранятся данные

  • Задачи, заметки и настройки хранятся на устройстве пользователя (в памяти приложения).
  • Если пользователь включает синхронизацию между устройствами, данные хранятся в приватном GitHub Gist в его собственном аккаунте GitHub, доступ — по его личному токену, который остаётся только на его устройствах.

Google Календарь

  • Приложение запрашивает доступ calendar.events, только если пользователь сам подключает свой Google Календарь.
  • Доступ используется, чтобы создавать, обновлять и удалять события для задач с дедлайнами и показывать события пользователя внутри приложения.
  • Токены доступа хранятся только на компьютере пользователя и никуда не передаются, кроме серверов Google.
  • Данные Google не продаются, не передаются третьим лицам и не используются для рекламы или обучения моделей.
  • Отключить доступ можно в приложении (кнопка ✕ во вкладке «Календарь») или на странице myaccount.google.com/permissions.

In English

Pixel Zadachnik is an open-source personal task tracker with no backend. All data stays on the user's devices (optionally synced through a private Gist in the user's own GitHub account). Google Calendar access (calendar.events) is requested only when the user connects their calendar, and is used solely to create, update and delete events for the user's own task deadlines and to display the user's events in the app. Tokens are stored locally and sent only to Google. Google user data is never sold, shared with third parties, or used for advertising or model training. Access can be revoked in the app or at myaccount.google.com/permissions.
