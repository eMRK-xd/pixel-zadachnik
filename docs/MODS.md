# Моды для Пиксельного задачника

Мод — это маленькая плитка в доке снизу справа (над кнопкой «отчёт»).
Каждый мод работает в своей песочнице (iframe с `sandbox="allow-scripts"`):
он не видит доску, ключ синка и не может вызывать команды приложения напрямую.
С приложением мод общается только через объект `zadachnik`, а доступ к данным
получает лишь тот, что указан в `permissions`.

Включить или выключить мод: ⚙ → «моды». Настройка своя на каждом устройстве.

## Где лежат моды

- **Встроенные** — `web/mods/<id>/`, список в `web/mods/index.json`.
- **Свои (на ПК)** — папка `mods` рядом с `Zadachnik.exe` (как в играх): `mods\<id>\`.
  Если туда нельзя писать (например, exe лежит в Program Files), используется `%APPDATA%\com.pixel.zadachnik\mods\`.
  Папку открывает кнопка ⚙ → моды → «папка модов», а «перечитать моды» подхватывает изменения без перезапуска.
  Свои моды по умолчанию выключены.

## Из чего состоит мод

```
mods/vinyl/
  mod.json     описание (обязательно)
  main.js      код (обязательно)
  style.css    стили (по желанию)
  body.html    разметка (по желанию)
  *.png …      картинки и звуки (по желанию), до 4 МБ на мод
```

`mod.json`:

```json
{
  "id": "vinyl",                 // латиница, цифры и дефис; уникальный
  "name": "Пластинка",
  "version": "1.0.0",
  "author": "кто сделал",
  "description": "одной-двумя фразами",
  "icon": "♫",
  "size": [300, 72],             // ширина 80–352, высота 24–160 (px)
  "permissions": ["media"],      // media | tasks | links
  "assets": ["cover.png"]        // только для встроенных: какие файлы подгрузить
}
```

## API: `window.zadachnik`

| вызов | что делает | доступ |
|---|---|---|
| `on(event, fn)` | подписка на события (ниже) | — |
| `toast(text)` | всплывашка внизу (не чаще раза в 1,5 с) | — |
| `sound(name)` | звук приложения: `pick add drop complete sync undo del` | — |
| `burst()` | искры над плиткой | — |
| `resize(h)` | поменять высоту плитки | — |
| `storage.get(k)` / `storage.set(k, v)` | своё хранилище мода, до 100 КБ | — |
| `asset(name)` | картинка/звук мода как `data:` URL | — |
| `tasks()` | список задач (текст, колонка, готово, дедлайн, подзадачи) | `tasks` |
| `open(url)` | открыть ссылку http(s) в браузере | `links` |
| `media.state()` / `media.art()` | что играет / обложка | `media` |
| `media.play() pause() toggle() next() prev()` | управление плеером | `media` |

Все вызовы возвращают Promise.

События:

- `ready` — `{mod, theme, tasks:{open,done}, visible}`;
- `theme` — тема или шрифт поменялись: `{loop, vars, font:{key, name, family, smooth}}`; CSS-переменные `--ink --dim --gold --panel --line …`, `--ff` и класс `loop` на `<html>` проставляются сами;
- `font` — `{key}`: шрифт приложения сменился и уже загружен, можно заново мерить ширину текста (бегущая строка и т.п.);
- `taskDone` / `taskUndone` — `{text, col, subtask}`;
- `tasks` — `{open, done}` после любого изменения;
- `visible` — окно показано или спрятано (останови анимацию, когда `false`);
- `media` — что играет: `{title, artist, album, playing, pos, dur, app, canNext, canPrev}` или `null`, примерно раз в 1,5 с (нужен `media`);
- `mediaArt` — обложка трека (`data:` URL) или `null` (нужен `media`).

«Что играет» берётся из медиа-сессий Windows, то есть из того же места, что и плашка громкости.
Поэтому работает со Spotify, браузером, Яндекс Музыкой и другими плеерами, но только в приложении на ПК.

## Шрифт

Мод сам пишет тем же шрифтом, что выбран в настройках приложения (⚙ → вид → шрифт): Pixelify, Handjet или Andika.
Его подставляет хост: правила `@font-face` приходят в песочницу готовыми, а имя шрифта лежит в CSS-переменной `--ff`.

- Ничего не делай, и всё будет как в приложении: у `body` уже стоит `font: 14px var(--ff)`.
- Своё `font-family` — только если мод правда должен выглядеть иначе. Тогда пиши `font-family: var(--ff)` там, где нужен шрифт приложения.
- `<html data-font="pix|handjet|andika">` — если для какого-то шрифта нужно подвинуть размеры, например `html[data-font=handjet] .title{font-size:16px}`.
- У Andika (не пиксельный, для лёгкого чтения) на `<html>` стоит класс `font-smooth`: сглаживание включено.
- Если мод меряет текст, подпишись на `zadachnik.on("font", …)` и перемерь.

## Как попробовать в браузере

Открой `index.html?fakemedia`. Вместо системного плеера заработает выдуманный, и медиа-моды можно проверять без сборки exe.

## Пример: счётчик за сегодня

`mod.json`: `{"id":"counter","name":"Счётчик","size":[140,40]}`

`main.js`:

```js
let n = 0;
document.body.innerHTML = '<div style="padding:10px;color:var(--gold)">сегодня: <b id="n">0</b></div>';
zadachnik.storage.get(new Date().toDateString()).then(v => { n = v || 0; show(); });
zadachnik.on("taskDone", () => { n++; show(); zadachnik.storage.set(new Date().toDateString(), n); if (n % 5 === 0) zadachnik.burst(); });
function show() { document.getElementById("n").textContent = n; }
```
